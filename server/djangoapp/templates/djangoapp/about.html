About Us

The Cars Dealership Review Application connects car buyers with dealerships across the United States. Our mission is to make it easy to find a trustworthy dealer near you by surfacing honest, sentiment-analyzed reviews from real customers.

This project was built as part of the IBM Full Stack Application Development Capstone, combining a Django backend, a Node.js/Express microservice backed by MongoDB, and a React single-page frontend, all containerized with Docker and deployed to Kubernetes.
